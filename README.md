# Итоговый проект по PostgreSQL

В итоговом проекте я написал запрос, который определяет, кто из руководителей проектов получит максимальную премию. По условию премия составляет 1% от общей стоимости завершённых проектов руководителя.

## Как устроен запрос

1. С помощью `JOIN` объединил таблицы проектов, сотрудников и персональных данных, чтобы получить ФИО руководителей.
2. Отобрал завершённые проекты, сгруппировал их по руководителям и рассчитал премию с помощью `SUM`.
3. В общем табличном выражении (`CTE`) присвоил руководителям места по размеру премии с помощью `RANK()`. Затем вывел ФИО, идентификатор и сумму премии для всех, кто занял первое место. Если максимальная премия одинакова у нескольких руководителей, запрос возвращает их всех.
